1. CREATE RAILWAY PROJECT
   - Go to https://railway.app
   - New Project → Deploy from GitHub (or empty + upload)
   - Or: railway init && railway up

2. UPLOAD CODE
   - Push this folder to a GitHub repo, connect to Railway
   - OR drag the zip / use Railway CLI

3. ENVIRONMENT VARIABLES (Railway → Variables)
   TELEGRAM_BOT_TOKEN = 8676309769:AAH9YxUZUzzwfl3ivuWkpFQ8x_5jo9F1N70
   SESSION_SECRET     = (any long random string)
   PORT               = (Railway sets this automatically)

4. DEPLOY
   - Railway will run: npm install → node server.js
   - Python3 is included via nixpacks for running user bots

5. CUSTOM DOMAIN (optional)
   - Railway → Settings → Domains → Generate

6. FIRST USE
   a) Open your Telegram bot (the one with token above)
   b) Send /start  → you get a MITZ-XXXX token (admin panel if your TG id is 8632939616)
   c) Open the website → Sign Up
      - Username
      - Gmail
      - Password + Confirm
      - Paste hosting token
   d) Dashboard → Deploy Bot
      - Name
      - Description (optional)
      - Upload ZIP of your Python bot
   e) Manage → start/stop/logs/rename/delete
