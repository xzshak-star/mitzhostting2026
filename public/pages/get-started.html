Get Started

Zero to live bot in minutes.

Step 1 — Token

Telegram bot → /start → copy your MITZ-... token.

Step 2 — Account

Sign Up with username, Gmail, password, confirm, and the token.

Step 3 — ZIP your bot

Put your Python files in a folder, zip it. Prefer main.py as entry.

Step 4 — Deploy

Dashboard → Deploy Bot → name + ZIP → Deploy. We auto-detect and start it.

Step 5 — Manage

Start / stop / restart / logs / rename / delete anytime.
