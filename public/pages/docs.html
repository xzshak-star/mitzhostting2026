Documentation

Deploy and manage Python bots on Mitz Hosting.

1. Get a Hosting Token

Open our Telegram bot and send /start. You receive a permanent token like MITZ-XXXX-XXXX-XXXX. It cannot be changed or revoked by you. Free tokens = 1 bot slot.

2. Create Account

Sign up with username, Gmail, password, confirm password, and paste the hosting token.

3. Deploy a Bot

  1. Dashboard → + Deploy Bot
  2. Enter name + optional description
  3. Upload a .zip of your project

ZIP rules:

  • Can contain folders and multiple files
  • If exactly one .py file → that becomes the entry point
  • Otherwise we look for main.py, bot.py, app.py, etc.

4. Manage

Click Manage on any bot to: start / stop / restart / rename / view logs / delete.

Limits

  • Free: 1 bot
  • Premium / Admin: set by admin via Telegram
